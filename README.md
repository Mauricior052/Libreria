# Library Management System

Inventory management system designed to streamline book stock control, loan tracking, and search processes.

## Tech Stack
* **Language:** Java 21
* **Database:** MySQL
* **Data Access:** JDBC
* **User Interface:** Java Swing

## Key Features
* **Stock Management:** Full CRUD operations for books and categories.
* **Search Engine:** Dynamic filtering by author, and title.
* **Loan Module:** Real-time tracking of check-outs, returns, and availability.
* **Data Security:** Implementation of PreparedStatements to prevent SQL Injection.

## Project Structure
* `src/model`: Data entities.
* `src/controller`: Business logic.
* `src/view`: UI components.
* `db/`: Database schema scripts.
